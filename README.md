## The joke

> I told my wife I was cutting back on dad jokes. She said, 'Finally, something you're cutting that isn't the grass.'

One original one-line dad joke, 115 characters.

## How it works

`main.ts` (Node 22, standard library only) writes the joke to `/output/entry.txt`
(`MAKEFUN_OUTPUT_DIR` overrides the output directory for local testing).
It validates the gate before writing: exactly one line, 1–140 characters,
not only whitespace.

```sh
node main.ts
```
